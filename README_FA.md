# پروژهٔ آزمایشی EquiFa

## ساخت APK با GitHub Actions
این پروژه عمداً به فایل‌های Gradle Wrapper وابسته نیست. Workflow خودش Gradle را روی سرور GitHub نصب می‌کند و APK آزمایشی را می‌سازد.

1. محتویات این پوشه را در ریشهٔ مخزن GitHub با همان ساختار پوشه‌ها بارگذاری کنید.
2. تغییرات را روی شاخهٔ `main` Commit کنید.
3. وارد زبانهٔ **Actions** شوید و اجرای **Build APK** را باز کنید.
4. وقتی وضعیت سبز شد، پایین صفحه در بخش **Artifacts** روی `EquiFa-debug-apk` بزنید تا ZIP حاوی APK را دریافت کنید.
5. ZIP را استخراج کنید و فایل `app-debug.apk` را به گوشی منتقل کنید.

## محدودیت مهم
این نسخه فقط یک نمونهٔ اولیه است: یک واژه‌نامهٔ محدود و آفلاین از عبارت‌های رایج دارد. ترجمهٔ کامل و هوشمند انگلیسی به فارسی برای تمام صفحه‌های Equilab در این نسخه پیاده‌سازی نشده است. متن‌هایی که برنامه به سرویس دسترس‌پذیری ارائه نمی‌کند نیز قابل خواندن نیستند.
