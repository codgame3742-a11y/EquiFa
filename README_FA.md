# پروژهٔ آزمایشی EquiFa

این پروژه یک نمونهٔ اولیهٔ اندروید است؛ APK از پیش ساخته‌شده در این ZIP وجود ندارد.

## ساخت APK با Android Studio
1. ZIP را استخراج کنید.
2. Android Studio را باز کنید و پوشهٔ `EquiFaProject` را انتخاب کنید.
3. منتظر بمانید Gradle Sync کامل شود. اتصال اینترنت برای دریافت وابستگی‌ها لازم است.
4. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** استفاده کنید.
5. در صورت موفقیت، فایل معمولاً در `app/build/outputs/apk/debug/app-debug.apk` خواهد بود.

## نکته‌های مهم
- این نمونه از AccessibilityService برای خواندن متن‌هایی استفاده می‌کند که اندروید در درخت دسترس‌پذیری نمایش می‌دهد.
- ترجمه در یک پنجرهٔ شناور نمایش داده می‌شود؛ متن اصلی برنامه را جایگزین نمی‌کند.
- متن‌های داخل تصویر، نقشه یا اجزای سفارشی ممکن است قابل‌خواندن نباشند.
- مدل ترجمهٔ انگلیسی به فارسی ممکن است در نسخهٔ فعلی ML Kit پشتیبانی نشود؛ در صورت خطای کامپایل یا اجرا باید آن را اصلاح کرد.
- سرویس دسترس‌پذیری دسترسی حساسی است. آن را فقط برای این هدف و وقتی لازم است فعال کنید.
